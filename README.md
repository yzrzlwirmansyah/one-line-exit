An IT-support technician quits in the only voice he has left: after a career of prescribing "turn it off and on again" to everyone else, he turns the fix on himself — one final power-down, with no reboot scheduled. The entry is a single 119-character line, his resignation effective today, and the program writes exactly that line (no trailing newline) to `entry.txt`.

## Run it

```bash
python3 main.py
```

By default it writes to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to change the destination.
